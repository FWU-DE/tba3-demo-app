Bausteine zum Einbauen

Building blocks for your own software

Wer eine eigene Rückmeldung baut, muss die Diagramme nicht neu zeichnen. Jede Visualisierung aus dem Komponentenkatalog gibt es hier als fertiges Softwarepaket (@tba3/bausteine), das sich in eine eigene Anwendung einbauen lässt: als Web Component, die in jeder Webseite läuft, und als Komponente für Vue und React. Alle drei Fassungen zeichnen mit demselben Code; unten stehen sie nebeneinander.

If you build your own report, you do not have to draw the charts again. Every visualisation from the component catalogue is available here as a ready-made software package (@tba3/bausteine) for your own application: as a web component that runs in any web page, and as a component for Vue and React. All three draw with the same code; they are shown side by side below.

Das Aussehen bestimmt die Anwendung, die einbaut: Farben, Schrift und Abstände werden von außen vorgegeben (über CSS-Variablen). Mit der Auswahl „Thema“ lässt sich ausprobieren, wie dieselben Diagramme in einer anderen Gestaltung aussehen.

The application that builds them in decides how they look: colours, type and spacing are set from outside (through CSS variables). Use the "Theme" selector to see the same charts in a different design.

Die Bausteine melden Klicks an die Anwendung zurück. Klick auf einen Balken, eine Zeile oder eine Spaltenüberschrift: die Meldung erscheint hier. The building blocks report clicks back to the application. Click a bar, a row or a column header: the message appears here.

Katalog und Bausteine

Catalogue and building blocks

Der Katalog zeigt jede Visualisierung mit Beispieldaten und erklärt, wofür sie gedacht ist. Er ist zum Anschauen da. Die Bausteine sind dieselben Visualisierungen zum Einbauen. Jede Katalog-Ansicht zeichnet mit dem Baustein, der in der Tabelle neben ihr steht.

The catalogue shows every visualisation with sample data and explains what it is for. It is there to look at. The building blocks are the same visualisations to build in. Every catalogue view draws with the building block listed next to it in the table.
