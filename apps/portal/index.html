Rückmeldungen aus VERA-Daten — von der Schnittstelle bis zur fertigen Ansicht

Reports from VERA data — from the API to the finished view

Die TBA3-Auswertungsschnittstelle liefert Kompetenzstufen, Aufgabenstatistiken und Aggregationen auf Lerngruppen-, Schul- und Landesebene. Hier liegt alles, was zeigt, was sich daraus bauen lässt: eine vollständige Demoanwendung, die einzelnen Visualisierungs-Bausteine und Beispiele fertiger Rückmeldungen.

The TBA3 reporting API delivers competence levels, item statistics and aggregations at learning group, school and state level. Everything that shows what can be built from it lives here: a complete demo application, the individual visualisation building blocks, and examples of finished reports.

Für wen ist das hier?

Who is this for?

Ministerien und pädagogische Institute

Ministries and educational institutes

Zum Anschauen und Anregen lassen: Die Prototypen zeigen, was sich aus VERA-Daten machen lässt, wenn die Auswertung über eine gemeinsame Schnittstelle läuft — von der Kompetenzstufenverteilung einer Klasse bis zur Rückmeldung an die Schulleitung.

For inspiration: the prototypes show what can be made of VERA data once the analysis runs through a shared API — from the competence level distribution of a class to the report that reaches the school leadership.

Nichts davon ist ein fertiges Produkt oder eine Vorgabe. Die Beispiele sind dazu da, im eigenen Haus zu vergleichen, zu diskutieren und weiterzudenken: Rückmeldungsbeispiele ansehen.

None of it is a finished product or a specification to follow. The examples are there to be compared, discussed and taken further in your own organisation: view the report examples.

Anbieter und Implementierende von Rückmeldungen

Vendors and implementers of reports

Zum direkten Nachnutzen: Demoanwendung, Komponentenbibliothek und die einzelnen Rückmeldungen liegen offen auf GitHub — samt Mock-Daten, mit denen sich alles ohne eigenes Backend ausprobieren lässt.

To reuse directly: the demo application, the component library and the individual reports are all on GitHub — including mock data, so everything can be tried out without a backend of your own.

Anpassungen, eigene Visualisierungen und weitere Rückmeldungen sind ausdrücklich erwünscht — als GitHub Issue oder Pull Request.

Adaptations, your own visualisations and further reports are expressly welcome — as a GitHub issue or a pull request.
